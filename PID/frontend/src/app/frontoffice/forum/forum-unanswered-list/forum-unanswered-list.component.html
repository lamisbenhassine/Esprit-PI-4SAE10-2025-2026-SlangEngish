Sujets sans réponse

Ici figurent uniquement les sujets où personne n’a encore écrit un message dans le fil de discussion (en base : aucune ligne forum_message pour ce sujet). Ce n’est pas la « pub » du fil d’actualité seule : dès qu’un étudiant (ou quelqu’un d’autre) poste un premier commentaire sur la page du sujet, celui-ci disparaît de cette liste — même si aucun tuteur n’a encore répondu.

Intérêt pour les tuteurs : repérer rapidement les discussions encore « muettes » pour lancer la conversation. Si la liste est vide, soit tout le monde a déjà reçu au moins une réponse dans le fil, soit les sujets viennent d’ailleurs (autre flux).
