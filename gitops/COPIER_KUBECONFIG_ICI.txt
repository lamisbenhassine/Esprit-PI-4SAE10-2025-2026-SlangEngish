Emplacement du kubeconfig admin (hors Git)
==========================================

1) Sur la VM master :
   sudo cat /etc/kubernetes/admin.conf

2) Sur ton PC (dans ce dépôt), crée le fichier EXACT :
   gitops/kubeconfig-kubeadm.yaml

   Colle-y TOUT le YAML affiché par la commande ci-dessus.

3) Ce fichier est ignoré par Git (voir .gitignore à la racine).
   Ne le commite jamais ; ne le partage pas publiquement.

4) Jenkins :
   - Credentials → Secret file
   - ID : kubeconfig-kubeadm
   - Contenu : le même YAML (ou upload ce fichier depuis ta machine).

5) Ne colle pas le contenu complet dans le chat / une issue : secrets.
